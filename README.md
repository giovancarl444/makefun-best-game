**Periapsis** — a minimalist orbital slingshot game. Drag back from your probe to aim, release to
burn, and let planetary gravity carry you through the gates. Collect every mote, reach the warp
ring, and do it in as few burns as you can.

## Run it

```sh
npx serve game
```

Or open `game/index.html` directly in a desktop browser. Everything is static: no network calls,
no build step, no external assets. `node main.ts` validates the files and copies them to `out/`.
